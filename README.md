# Zenith Portfolio

Static portfolio for `zenith-8-bit.github.io`.

## Structure
- `index.html` — landing page
- `projects.html` — project index / work log
- `blog.html` — future journal/blog landing page
- `assets/style.css` — shared visual system
- `assets/app.js` — scroll progress, navbar, mobile menu, reveal effects, typing effect and cursor
- `blog/` — reserved for future posts
- `projects/` — reserved for future long-form project pages

## Deploy
This is a plain static GitHub Pages site. Copy the contents of this folder into the root of `zenith-8-bit/zenith.github.io` and push to the default branch.

No build step is required.
